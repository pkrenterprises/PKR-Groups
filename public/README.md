# PKR Groups Corporate Website

Deployment-ready static website for PKR Groups.

## Included
- Responsive corporate homepage
- PKR Groups business portfolio
- AKSHIRA, AMRIT, SHRIVAINA, KSHITRIVA, KR Nurseries, VAYUPRABA Technologies, SARVAMPADA, SHEEGRA and MSR Charitable Trust
- CEO profile link
- SEO title/description/keywords
- Organization JSON-LD structured data
- Open Graph metadata
- robots.txt and sitemap.xml
- Enquiry form using mailto
- No build step or external dependencies

## Deploy
Upload the contents of this folder to any static host such as Netlify, Vercel, GitHub Pages, Cloudflare Pages, or a normal web server.

## Before going live
1. Replace `https://pkrgroups.com/` with the final corporate domain if different.
2. Add official logos and CEO photograph when available.
3. Update contact details and social links.
4. Submit sitemap.xml to Google Search Console and Bing Webmaster Tools.
5. Configure the final domain and HTTPS.
